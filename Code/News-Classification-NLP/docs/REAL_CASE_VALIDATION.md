# Real-Case Validation

## 1) Benchmark validation (labeled)
Use the holdout test split generated by preprocessing.

Command flow:
1. `python run_preprocessing.py --data-dir data/raw --out-dir data/processed`
2. `python train_baseline_models.py --processed-dir data/processed`
3. `python train_advanced_models.py --processed-dir data/processed`
4. In app tab **Benchmark Validation**, run holdout scoring.

This produces reproducible labeled metrics (Accuracy, Precision, Recall, F1, confusion matrix).

## 2) Live URL validation (unlabeled)
Use app tab **Live URL Validation**.

Process:
- Fetch URL text via `trafilatura` (primary) or BeautifulSoup fallback.
- Run classifier prediction on extracted text.
- Show confidence with explicit inference-only disclaimer.

## Expected behavior
- If extraction fails, UI provides manual text fallback.
- URL mode does not claim factual verification because labels are not available.
