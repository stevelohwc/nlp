# Setup Development Environment

Set up the Python development environment for the NLP assignment project.

## Steps

1. Check if virtual environment exists
2. Create virtual environment if needed
3. Activate virtual environment
4. Install or update dependencies from requirements.txt
5. Verify installation by checking key packages (numpy, pandas, scikit-learn, nltk)
6. Download required NLTK data if needed
7. Create Code/ directory structure if it doesn't exist

## Success Criteria

- Virtual environment is created and activated
- All dependencies are installed successfully
- NLTK data is downloaded
- Directory structure is in place
- Report success with Python version and installed package counts
