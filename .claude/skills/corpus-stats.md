# Check Corpus Statistics

Analyze the corpus data used for spelling correction and report key statistics.

## Steps

1. Locate corpus files in Code/datasets/ or Code/spelling_correction/
2. Read and process corpus files
3. Calculate and report:
   - Total word count
   - Unique word count
   - Vocabulary size
   - Top 20 most frequent words
   - Word length distribution
   - Check if minimum 100,000 word requirement is met
4. Display results in clear, formatted output

## Success Criteria

- Corpus files are located and readable
- Word count meets assignment requirement (100,000+ words)
- Statistics are calculated accurately
- Results are displayed in user-friendly format

## Notes

- Assignment requires minimum 100,000 words from scientific field
- If corpus is insufficient, provide recommendations
- Support multiple file formats (txt, csv, json)
